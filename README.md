# szcore_death

SzCore v1.4.0-rc1 medical/death foundation.

Tracks body-part injuries, bleeding, pain, last stand and death; provides hospital respawn, EMS help alerts, EMS treatment/revive callbacks and usable medical items.

Dependencies: `szcore`, `szcore_ui`, `szcore_inventory`, `szcore_status`.

Commands when enabled: `/status`, `/emstreat`, `/revivep`, `/911e`.
